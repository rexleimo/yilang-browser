一览 Yilan 是什么？

一览 Yilan 是一款免费、免登录的移动浏览器，采用 iOS 原生设计风格，以书签管理为核心体验。它提供 iOS 风格的网格书签首页、多标签与无痕浏览、阅读模式、可离线归档的阅读清单、下载中心和一键网页翻译，支持 iOS 与 Android 双端，书签可通过标准 Netscape HTML 与其他浏览器互通。

适合谁用？

适合重书签用户、稍后读爱好者，以及想要一个轻快、干净、数据完全本地化的浏览器的人。无需注册账号，安装即用；历史、Cookie、缓存随时可清，书签随时可带走。

FAQ · 常见问题

你想知道的，
都在这。

我的书签和数据会上传到云端吗？

不会。书签、历史、阅读清单均保存在你的设备本地，无账号体系、无强制云同步；需要迁移时使用标准 Netscape HTML 导入导出，数据始终归你所有。

支持哪些平台和系统版本？

基于 Flutter 构建，iOS 使用 WKWebView、Android 使用系统 WebView。iOS 与 Android 双端同步迭代，安装包按 CPU 架构拆分，体积更轻。

怎么把旧浏览器的书签迁移过来？

在旧浏览器导出 Netscape 格式 HTML 书签文件，再在一览的设置中导入即可，文件夹结构完整保留；同样支持随时导出备份。

阅读清单离线归档是什么？

加入阅读清单的页面可离线归档净化副本，即使断网也能完整阅读正文与配图；已读未读状态一目了然，读完可一键转为书签。
